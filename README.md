VictoriaMetrics RISC-V64

RISC-V64 build of VictoriaMetrics Single-node distributed as a Snap package.

The package provides VictoriaMetrics for linux/riscv64 systems using the official upstream source.

* VictoriaMetrics: v1.152.0
* Architecture: RISC-V 64-bit (riscv64)
* Snap base: Ubuntu Core 26 (core24)
* Confinement: strict

The upstream VictoriaMetrics source is used unchanged and downloaded directly from the official repository during the build.

This repository contains the Snap packaging configuration for the RISC-V64 build. It does not contain the VictoriaMetrics source code.
